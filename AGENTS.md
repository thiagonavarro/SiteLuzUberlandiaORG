# Luz Uberlândia — instruções do projeto

O repositório padrão e canônico para o site que estamos desenvolvendo é https://github.com/thiagonavarro/SiteLuzUberlandiaORG (branch principal: main).

Use esse repositório para as próximas alterações e entregas deste site. Antes de alterar, obtenha a versão mais recente e preserve mudanças existentes. Não crie outro repositório para este projeto sem solicitação do usuário.

O WordPress completo está na raiz para deploy direto em public_html. O plugin wp-content/plugins/luz-privacidade contém políticas editáveis, banner e formulário de contato. O tema wp-content/themes/luz-uberlandia contém a conversão WordPress da versão do ChatGPT Sites. Os arquivos ZIP em packages são os pacotes de instalação; mantenha-os coerentes com o código-fonte ao gerar novas entregas.

O destino provisório confirmado é logical-white-wolf-19.hostingersite.com, com deploy Git de main e origem na raiz. O domínio luzuberlandia.org.br usa Horizons e não deve ser substituído sem pedido do usuário. A primeira instalação do banco e da conta administrativa precisa ser concluída na hospedagem. Consulte README.md e LEIA-ME.txt para validações pendentes, inclusive inventário real de cookies e entrega de e-mails. E-mail informado pelo usuário: contato@luzuberlandia.org.br. Nunca envie wp-config.php, credenciais, uploads ou dados de contatos ao Git.

A publicação anterior no ChatGPT Sites usa infraestrutura e repositório internos próprios. O GitHub acima é o repositório padrão de desenvolvimento solicitado; isso não configura automaticamente deploy na Hostinger nem altera a integração interna do Sites.
